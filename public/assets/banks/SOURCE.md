# Logos de bancos

Os SVGs desta pasta foram obtidos de `Tgentil/Bancos-em-SVG`, commit `fe1d43f`.

O repositório de origem informa que as marcas pertencem às respectivas instituições e devem ser utilizadas em conformidade com suas diretrizes de marca. Os arquivos são versionados localmente para que a interface não dependa de CDN de terceiros em tempo de execução.
